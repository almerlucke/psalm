# Examples

The examples live in `cmd/examples` and play live through PortAudio until you press Ctrl+C.
Run them from the repository root (they load sounds from `assets/`):

```
go run ./cmd/examples/<name>
```

The examples that let you play one instrument and try its presets live in `cmd/examples/instruments/<name>`
(`go run ./cmd/examples/instruments/waveguide`, `.../modal`), to keep this folder from growing. They share
one page, `cmd/examples/instruments/audition`: an example describes its synth (its presets, how to
make and describe one, its test phrases) and the page does the rest. The piano tour is
`cmd/examples/instruments/piano`.

The complete pieces live in `cmd/songs` (`go run ./cmd/songs/morningstar`, `go run ./cmd/songs/creation`, `go run ./cmd/songs/awaken`, `go run ./cmd/songs/mercy`).

Most have a commented out `p.ToSoundFile(...)` call: uncomment it (and comment out
`p.Listen()`) to render to a file instead.

**New to arranging in psalm?** Start with the tutorial in
[`cmd/examples/tutorial`](../cmd/examples/tutorial/README.md): eighteen short programs, one idea
each, from a single note to a whole song (notes, the form, bars and chords, feel, the harmony
check, automation, curves at bars, tempo, events, the mixer, streams, tuning), a control panel to
play it live and a drum machine, every step playable.
