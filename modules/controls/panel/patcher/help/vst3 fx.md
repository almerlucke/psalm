# vst3 fx

An **effect from a VST3 plugin** installed on this machine: the sound goes in, the plugin changes it, the sound comes out. Each effect found is a preset of this kind; the kind is only there when psalm found a plugin. Its parameters are the settings of the module, and the second input of an effect is its side chain.

Cable the `in` and `out` like any effect and open the settings to move the parameters. The rest is as for [vst3](vst3.md).
